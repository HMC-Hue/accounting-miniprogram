## 📦 项目说明

这是一个用微信原生小程序语法开发的记账小程序，包含：
- **首页**：本月结余统计卡片、收入/支出数据、功能图标、记账记录列表
- **添加页**：收入/支出切换、金额输入、分类选择、日期选择、备注
- **预算功能**：按月设置预算，首页用进度条展示已用比例，剩余额度与超支红色提醒
- **数据存储**：微信本地存储 API（wx.setStorageSync），记录与预算分别存储
- **内置示例数据**：3条示例记录，打开就能看到效果

### 本次优化记录
- 修复功能图标无反应的问题：预算图标进入预算设置，其余图标点击有真实反馈
- 新增月度预算设置、进度条、剩余额度与超支提醒
- 列表标题改为"记账记录"，日期分组显示"今天 / 昨天 / M月D日"
- 修复快速连续保存时 id 可能重复、导致误删的隐患，id 保证唯一

## 🚀 怎么打开项目

### 第一步：下载微信开发者工具

如果还没安装，去官网下载：
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

安装后用微信扫码登录。

### 第二步：导入项目

1. 打开微信开发者工具
2. 点击 **"+" 号** 或 **"导入项目"**
3. 项目目录选择：
   ```
   C:\Users\崔丽娟\Doubao\chats\2026-10-30\new-chat-2\accounting-app
   ```
4. AppID 选择 **"测试号"**（或者点击"使用测试号"）
5. 项目名称随便填，比如 `记账小程序`
6. 点击 **"确定"**

导入后会自动编译，左侧模拟器就能看到小程序界面了。

## ⚠️ 常见问题

**Q: 提示 AppID 错误怎么办？**
A: 导入时选择"测试号"就行，不需要真的注册小程序。

**Q: 模拟器空白怎么办？**
A: 点击开发者工具顶部的"编译"按钮重新编译，或者检查控制台报错。

**Q: 数据存在哪里？**
A: 存在微信的本地存储里，用 wx.getStorageSync 就能读到。
